# Glimmer

> 个人 IT 学习笔记与经验积累仓库。点滴积累，聚微光成星河。

## 目录结构

```
Glimmer/
├── notes/                  # 学习笔记
│   ├── frontend/           # 前端技术
│   ├── backend/            # 后端技术
│   ├── devops/             # DevOps & CI/CD
│   ├── database/           # 数据库
│   ├── algorithm/          # 算法与数据结构
│   ├── system-design/      # 系统设计
│   └── ai-ml/              # AI / 机器学习
├── experience/             # 经验积累
│   ├── troubleshooting/    # 踩坑记录 & 故障排查
│   ├── best-practices/     # 最佳实践
│   └── code-snippets/      # 实用代码片段
├── books/                  # 读书笔记
└── projects/               # 项目复盘 & 总结
```

## 使用方式

每个分类下按主题创建 Markdown 文件，命名示例：`2024-docker-networking.md`、`react-hooks-pitfalls.md`。

内容建议包含：
- **问题背景** — 遇到了什么问题 / 要学什么
- **核心内容** — 解决方案、原理分析、代码示例
- **总结** — 关键要点、参考资料
