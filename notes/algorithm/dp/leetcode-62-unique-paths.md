## 题目描述

一个机器人位于一个 `m x n` 网格的左上角（起始点记为 `(0, 0)`）。

机器人每次只能**向下**或**向右**移动一步。机器人试图达到网格的右下角（记为 `(m - 1, n - 1)`）。

问总共有多少条不同的路径？

### 示例

```
输入：m = 3, n = 7
输出：28
```

```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角：
1. 右 → 右 → 下
2. 右 → 下 → 右
3. 下 → 右 → 右
```

```
输入：m = 7, n = 3
输出：28
```

### 约束

- `1 <= m, n <= 100`
- 题目数据保证答案小于等于 `2 * 10^9`

## 解题思路

### 核心思想：DP 递推

到达每个格子的路径数 = **到达它上方格子的路径数 + 到达它左侧格子的路径数**。

因为只能从上方或左方走进当前格子：

```text
定义 dp[i][j] = 到达 (i, j) 的路径数

状态转移：dp[i][j] = dp[i-1][j] + dp[i][j-1]
初始化：   dp[0][*] = 1（第一行只能从左边来）
           dp[*][0] = 1（第一列只能从上面来）

目标：     dp[m-1][n-1]
```

### DP 表格推演（m=3, n=3）

```text
初始化：
  1  1  1    ← 第一行全 1（只能一直往右）
  1  ?  ?    ← 第一列全 1（只能一直往下）
  1  ?  ?    ← 第三行

递推：
dp[1][1] = dp[0][1] + dp[1][0] = 1 + 1 = 2
dp[1][2] = dp[0][2] + dp[1][1] = 1 + 2 = 3
dp[2][1] = dp[1][1] + dp[2][0] = 2 + 1 = 3
dp[2][2] = dp[1][2] + dp[2][1] = 3 + 3 = 6

最终表格：
  1  1  1
  1  2  3
  1  3  6  ← 答案 6
```

### 空间优化：滚动数组

`dp[i][j]` 只依赖上一行和当前行左侧，二维数组可压缩为一维：

```text
dp[j] = dp[j] + dp[j-1]
        ↑       ↑
     上一行同列  当前行左侧
```

初始化 `dp[0..n-1] = 1`（第一行全 1），然后逐行滚动更新。

### 数学解法：组合数

共需要走 `(m-1) + (n-1) = m+n-2` 步，其中选 `m-1` 步向下（其余向右），结果 = C(m+n-2, m-1)。

```text
C(m+n-2, m-1) = (m+n-2)! / [(m-1)! × (n-1)!]
```

> DP 是通用解法（可扩展到含障碍物 #63），数学公式仅在此题无额外约束时可用。

### 复杂度分析

| 维度 | 二维 DP | 一维 DP 优化 | 数学公式 |
|------|---------|-------------|---------|
| 时间 | O(m·n) | O(m·n) | O(min(m,n)) |
| 空间 | O(m·n) | O(n) | O(1) |

## 代码实现

### Java（二维 DP 标准版）

```java
class Solution {
    public int uniquePaths(int m, int n) {
        // 1. dp数组及下标含义：dp[i][j] = 到达(i,j)的路径数
        int[][] dp = new int[m][n];

        // 2. 递推公式：dp[i][j] = dp[i-1][j] + dp[i][j-1]
        //    上方位 + 左侧位 = 到达当前位置的总路径数

        // 3. dp数组初始化：第一行和第一列都只有一方向可达，均为1
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;

        // 4. 遍历顺序：从上到下、从左到右，确保依赖的格子已计算
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        return dp[m - 1][n - 1];
    }
}
```

### Java（一维 DP 空间优化版）

```java
class Solution {
    public int uniquePaths(int m, int n) {
        // 1. dp数组及下标含义：dp[j] = 到达当前行第j列的路径数
        //    只用一维数组，每行滚动复用
        int[] dp = new int[n];

        // 2. 递推公式：dp[j] += dp[j-1]
        //    dp[j] 此时是上一行同列的值，dp[j-1] 是本行刚算出的值

        // 3. dp数组初始化：第一行全1（只能一直往右走）
        for (int j = 0; j < n; j++) {
            dp[j] = 1;
        }

        // 4. 遍历顺序：从第二行开始逐行滚动，每行内从左到右
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j] + dp[j - 1];
            }
        }

        return dp[n - 1];
    }
}
```

## 关键点总结

1. **状态定义**：`dp[i][j]` 表示到达 `(i,j)` 的路径数——找状态比写递推更难，这道题的状态是 DP 入门最经典的"数量累加型"
2. **递推方向**：从左到右、从上到下，确保计算 `dp[i][j]` 时 `dp[i-1][j]` 和 `dp[i][j-1]` 都已算好
3. **边界初始化**：第一行和第一列只能从一个方向到达，全部初始化为 `1`
4. **空间优化本质**：滚动数组能用的前提是**当前行只依赖上一行**——不是所有 DP 都能压维
5. **与 #63 的关系**：两题结构相同，但 #63 加了障碍物条件（遇到障碍物 `dp[i][j] = 0`），这是 DP 的经典变体
