## 题目描述

给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明**：你不能倾斜容器。

### 示例

```
输入：[1,8,6,2,5,4,8,3,7]
输出：49
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。
在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。

输入：height = [1,1]
输出：1
```

### 约束

- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

> **注意**：n 可达 10⁴，O(n²) 的暴力枚举会超时，需要 O(n) 解法。

---

## 解题思路

### 核心思想：贪心 + 相向双指针

容器的盛水量 = `min(height[left], height[right]) × (right - left)`，由两个维度决定：

- **宽度**：左右指针距离 `(right - left)`
- **高度**：两根柱子中较低的那根 `min(height[left], height[right])`

暴力法是枚举所有 `O(n²)` 种左右组合。优化关键：**能否在每次移动时，只舍弃不可能成为最优解的组合？**

```
初始状态：left = 0, right = n-1（宽度最大）

每轮计算当前容量，然后移动较短的指针：
  if height[left] < height[right]:
      left++      ← 移动较短的，期望找到更高的柱
  else:
      right--     ← 同理

为什么移动较短的一边：
  移动较高的一边 → 宽度-1，高度不变或更低 → 容量不可能变大
  移动较短的一边 → 宽度-1，高度可能变大 → 容量有概率增加

终止：left == right（相遇）
```

### 贪心正确性证明（一句话版）

**面积 = 宽度 × 最小高度**。从最宽（两端）开始，宽度只会越来越窄。想增大面积，唯一的希望是**拉高最小高度**——所以每次移动较矮的柱。移动较高的柱只会让面积更差，没有检查的价值。

### 复杂度分析

| 维度 | 复杂度 |
|------|--------|
| 时间 | O(n) — 两个指针各自最多移动 n 次 |
| 空间 | O(1) — 只用了几个变量 |

## 代码实现

### Java

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            int w = right - left;                        // 宽度
            int h = Math.min(height[left], height[right]); // 高度
            maxArea = Math.max(maxArea, w * h);

            // 移动较短的柱：期望找到更高的来增大面积
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxArea;
    }
}
```

---

## 关键点总结

1. **面积的两个因子**：宽度「只会变小」，提高面积的唯一手段是拉高较矮柱
2. **移动较矮的**：这是双指针相向移动的核心决策——每次都舍弃不可能成为最优解的一边
3. **贪心证明**：因为移动较高柱宽度-1且高度必不增长 → 面积只会更差 → 没有检查必要
4. **双指针与滑窗的区别**：双指针是「相向移动」压缩搜索空间，滑窗是「同向移动」维护窗口
5. **与 #42 接雨水的对比**：#11 求两根柱围成的最大矩形面积，#42 求所有柱围成的凹陷体积——思路完全不同
